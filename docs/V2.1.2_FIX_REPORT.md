## F01 严格导入校验

根因：currentLesson/theme/mode 使用 String(value) 做白名单判断，然后把原值断言为字符串。单元素数组可以通过判断，却仍保留为数组，可能令首页找不到课程。

修改 `src/lib/storage.ts`：currentLesson 必须是真字符串并属于课程 ID；theme/mode 采用字面量类型分支验证，移除相应错误断言。保留完整对象验证后才返回新对象的原子导入方式，继续验证版本、课程记录、分数、错题 ID、笔记、收藏与复习统计。schema 仍为 1，无 reviews 的合法旧备份继续加载。

UI 先 parseProgress，成功且用户确认后才调用显式 replace；解析失败只设置错误提示，不更新当前数据。写入失败也不部分切换内存档案。

## F02 原始数据保护

根因：readProgress 返回默认值但未区分首次使用和读取失败，Provider 在 ready 后无条件把默认值写回原 key。

修改：

- `src/lib/storage.ts` 返回 first-use / loaded / read-error，并保留 raw：null 表示不存在，undefined 表示无法读取，字符串包含空串也是原始数据。
- 新增 `src/lib/storage-session.ts`，提供可单测的存储会话。read-error/conflict 时普通 save 禁止写入。写入前核对当前原文与已读快照；检测变化则暂停保存并提示其他标签页冲突。
- `src/components/learning-provider.tsx` 使用同一会话执行加载、普通保存和明确替换。写入异常被捕获并显示；即使存储不可用也能阅读和在内存中学习。主题仍可切换。
- `src/components/progress-view.tsx` 提供“导出原始数据”，将原文字节作为 application/octet-stream 的 .txt 下载，不插入 HTML、不执行。文件可能包含隐私，应妥善保存。
- 只有用户已确认的导入/重置调用 replace。正常更新、课程访问、笔记、主题变化不能越过保护。取消确认不调用替换；替换失败不切换成部分导入对象。

没有复制用户浏览器的真实档案。单元测试使用内存假存储；Playwright 用新浏览器上下文中的人工数据，种子不来自真实个人资料。

保护边界：读权限彻底不可用时无法取得原文，导出原始数据按钮禁用；仍可导出临时内存档案。多标签页使用写入前快照检查做风险隔离，不合并数据。localStorage 缺少跨标签页原子 compare-and-swap，两个进程在极小窗口同时读写仍有竞态，不能宣称彻底消除数据丢失。浏览器清理、磁盘故障也无法由此恢复，请保留备份。

## F03 词汇队列

根因：当前题来自 lockedWord，但导航仅按过滤后 words.length 禁用；答对后当前词离开“待巩固”，剩一词时被错误地禁止导航，最后一词也没有结束状态。

修改：新增 `src/lib/review-queue.ts`，集中推导当前题、锁定题是否已离队、前后导航、完成操作和空队列状态。在 `src/components/vocabulary-view.tsx` 复用该逻辑：

- 2→1：保留已答题解释，但仍可进入剩下的一词。
- 1→0：显示“完成复习”，确认后显示“本轮复习已完成”，不保留伪造的下一词。
- 初始无匹配项仍显示空筛选提示，和完成状态区分。
- 收藏移除当前词、已掌握/待巩固变化均通过当前锁定状态与队列重新计算索引。
- 普通单词结果确实仅一项且当前词仍在队列时，前后保持禁用，不是草率移除所有 disabled。
- 题目提交后选项继续禁用，record 对已有 choice 再次调用不重复计数；切换方式/筛选重置本轮状态。
