## 2. 技术结构与依赖

这是标准 Next.js App Router 应用，页面服务端路由配合客户端学习组件；无业务 API、后端数据库或身份系统。根布局包含 LearningProvider 与 Shell。React Context + useState 管理全站档案，localStorage 为唯一持久化。内容是本地 TypeScript 数据，计算和评分逻辑为独立函数。

## 4. 主要代码问题与证据

### F01 / P1：导入枚举用 String 转换校验，接受错误类型

`src/lib/storage.ts:38–40` 对 currentLesson/theme/mode 先 String() 再校验，最后用类型断言直接赋值。把合法备份的 currentLesson 改成单元素数组 `["network-foundations"]`，本轮以内存加载当前 TS 模块实际调用 parseProgress：返回对象仍是数组，课程严格相等查询结果为 undefined。`overview.tsx` 对查询使用非空断言，随后访问 current.id，形成首页异常风险。theme/mode 同类数组也可被放行。**这是实际解析器复现，不是浏览器崩溃实测**。

应逐字段检查 typeof 和白名单，禁止通过强制转换与断言冒充验证；导入失败前后都应保留当前档案。没有发现这里会执行导入代码，不能将类型缺陷描述为代码执行漏洞。

### F02 / P1：读入失败后自动覆盖损坏原文

`readProgress` 捕获解析/版本失败，返回初始档案和 warning；Provider 随后 ready=true，写入 effect 无条件 setItem 同一 `cyberpath.v1`。原文可能仍含可恢复的笔记，但会被新档案覆盖。内存调用确认失败会返回初始对象；覆盖链路由两处源码共同确认，本轮未进行真实浏览器存储复现。多标签页无 storage 事件/冲突策略，也会造成旧快照覆盖新记录。优先备份原文、区分读写失败、禁止无确认覆盖，后续设计 revision 冲突提示。

### F03 / P1：词汇筛选队列与锁定题目不一致

`vocabulary-view.tsx:30` 用 lockedWord 保留已答题；按钮 `:291/:299` 却按过滤后 words.length<=1 禁用。待巩固中剩 packet/protocol，答对 packet 后，它被标 known 并移出队列，lockedWord 仍是 packet，剩余长度 1，两按钮禁用，protocol 无法继续。若最后一词被移出，旧题与 1/1 计数还会停留，缺少完成页。内存边界演算确认该禁用条件，源码流程确认状态变化；**本轮未完成浏览器端复现**。需明确“当前题/下一题/队列结束”语义，不只是移除全部禁用条件。

### F04 / P2：最近成绩混用访问时间

`overview.tsx:75–79` 按 RecordEntry.updated 排序选择 latest 不为空的课；LessonView 访问课程也更新 updated。先考 L1、再考 L2、最后仅重访 L1，首页就可能把 L1 当最近成绩。数据没有独立 lastQuizAt，不能准确恢复真实测验时间。需拆分访问/完成/作答时间；旧数据不能伪造精确时间，迁移时允许未知。

### F05 / P2：课程数据契约扩展依赖隐式位置

Lesson.labs 是 string[]，渲染靠 `as LabId`；available 布尔无法在类型上保证完整正文。course-summaries 按 number-1 索引，扩展词库也按课数组顺序关联；新增课还需补 initialProgress、校验及硬编码完成率。删除/改名现有章节标题会令旧备份的 section 校验失败，并触发 F02。建议稳定 lesson/section/question ID、明确预告/可用类型、小型内容校验，不引入新 CMS。

### F06 / P2：测验/错题数据不够表达长期学习

gradeQuiz 的边界检查正确，最新/最高分独立；但只存分数与最近错误 ID，不存实际选项或尝试时间。题目解释与答案都在前端内容中，对自学平台合理，不能当高风险考试系统。跨课客户端切换时 Quiz/Term 的局部状态是否保留、导入/重置后当前测验是否失配，需要回归验证，**尚未确认是现有 bug**，不可直接据此大改。

### F07 / P2：零基础教学支架和词汇覆盖不足

课程长段落包含尚未展开的 MAC/DHCP/ARP/TLS 等术语；词库只有 34 个词，目标/题目/命令解释未复用注释器。正文每次出现同一词都注释会打断阅读；正则只支持原词加 s，无不规则词形、多词短语或转义策略。词汇 known 只代表最近一次自评/对错，不能等同长期掌握；干扰项按固定 slice 生成且中文排序，容易记位置。宜先优化三课，不重写全部教材。

### F08 / P2：无障碍与反馈需针对实际任务验收

普通按钮有 focus、aria 标签及移动高度；但 `.inline-term button` 覆盖 min-height:auto，密集内嵌词需独立触控方案。英文正文设 lang=en，英文标题、目标、测验部分仍继承 zh-CN；缺少读屏人工验证。错误/词汇正确状态有文字提示，不能单纯认定只靠颜色。没有自动对比度、焦点遮挡或底栏与软键盘测试。

### F09 / P2：启动/构建与测试可靠性

开发与生产目录已分开，生产输出仍为固定目录；对正在运行的同目录服务再次 build 可能让旧进程使用新资产，需隔离构建与启动流程。本轮静态输出因 EPERM 失败，不能归因为 TS/React 编译错误。需在可正常写入的受支持环境验证干净构建，并加 CI；不应靠关闭沙箱或改系统安全设置处理。现有 Playwright 需要先成功构建，不能从启动失败推断某个 UI 功能坏了。

### F10 / P3：维护与性能风险

Provider 每次笔记/收藏更新都重绘订阅者并同步序列化完整档案；storage 又引入整套教材和词库，客户端有内容耦合。globals.css 叠加多个版本覆盖与断点，同一选择器重复；大型 VocabularyView、Labs、ProgressView 包含筛选/评分/存储/展示逻辑。建议按任务拆小模块并测量 bundle/输入延迟，不未经测量就添加 Redux、缓存层或整体重构。无性能跑分，本轮不能声称卡顿或达到某个性能指标。

## 5. 课程质量审查

三课依次为网络基础 → DNS/传输/Web → 地址/子网/路由/NAT，共 6+7+7 节、每课五题，顺序总体合理。英文为自然技术说明，无 lorem ipsum 或明显虚假已完成成果。目录后五课是明确预告，不应按大量正文占位计算。15 道题逐项检查：答案索引与题意一致，没有发现多正确选项的明显歧义；评分算法测试只能证明与题库索引一致，内容正确性仍靠本轮人工阅读。

| HTTPS/TLS    | 传输机密性/完整性、证书检查与“不保证网站诚实/无恶意软件”的边界正确                      | 加证书名不匹配与钓鱼示例；加密定义可强调密钥，避免误解授权会自动阻止密文被窃取 |
| Windows 实践 | ipconfig/ping 本地回环/nslookup/Test-NetConnection/route print/tracert 均是文本诊断练习 | 增加脱敏的输出片段与判断题；不从网页执行命令                                   |

教材概念核对参考：[RFC 1918](https://www.rfc-editor.org/info/rfc1918/)、[RFC 3021](https://www.rfc-editor.org/info/rfc3021/)、[RFC 5737](https://www.rfc-editor.org/info/rfc5737/)、[RFC 9114](https://www.rfc-editor.org/rfc/rfc9114.html)。示例公网样式地址属于文档保留地址，正文与实验都有提示。没有发现把 NAT 写成防火墙、把 HTTPS 写成网站安全保证、把 IPv6 写成必须做 IPv4 NAT 等概念性错误。

教学适配结论：主题覆盖足够作为入门阅读材料，但不足以证明零基础用户能独立完成任务。应增加短段落、术语首次出现支持、阅读目标到实验到题目的对应关系。L1 直接嵌 TCP 实验早于正式 TCP 教学，宜改为课后预览或提供基础连接图，L2 再正式展开。

## 6. 安全、部署及扩展边界

未发现 API Key、dangerouslySetInnerHTML、任意系统命令执行、外部扫描接口或追踪 SDK；笔记和 JSON 文本通过 React 转义，导入重建白名单字段并有大小限制。当前最大风险是本地数据的可靠性与校验，而非不存在的账号权限漏洞。客户端可自行修改成绩属于自学模型的固有限制。

有 nosniff、DENY、Referrer-Policy 和权限策略头；未配置 CSP/HSTS，不能将其自动视为漏洞或随意加会阻断 Next 脚本的 CSP。HTTPS 应在托管边界确认，开发 HTTP 不应硬套 HSTS。没有 CI、托管配置、部署自动化、数据库迁移或可核验的公网地址；README 中是部署建议。Manifest 不是离线缓存；未实现 SW 是清晰边界，不能伪称离线可用。

未来可在现有数据读写边界增加云适配，不需要替换 Next/React。必须先稳定 ID、迁移和事件语义，再考虑账号、权限、冲突合并。AI 教师可独立接入后端、限流和内容引用，但不属于 V2.2 必做项。
