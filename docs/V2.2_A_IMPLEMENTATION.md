## 阶段二：V2.2-A

### 已实现

- 三课 20 个章节均有显式稳定 ID；课程 ID 保留原值。
- 桌面章节目录、手机折叠目录、当前章节高亮和上一/下一章节。目录是实际锚点，无 JS 时仍能跳转；JS 可用时同时定位和保存。
- 250ms 节流观察阅读位置，记录课程、章节和章节内比例；刷新恢复，显式章节链接优先，匹配已有书签时保留章节内比例。滚动到下方实验/测验时不覆盖最后阅读书签。
- 首页 Continue Learning 指向保存的稳定章节。阅读/打开课程只更新 visited 与阅读信息，不更新 completed。
- 跨课按课程 ID 重新挂载阅读与测验，前后课程使用可用课程索引，不再假设课号连续。
- 英文正文限制 68ch、增加行高与移动排版；标题和目标标记 lang=en。段内首次出现的术语默认给中文提示，重复出现仍可点击解释；挑战模式保留。
- Windows 命令使用可换行的 pre/code 与原复制/失败提示；沿用原有主题变量。

### 数据兼容与未来加课

存储 key `cyberpath.v1` 和 schema `version:1` 不变。新增可选 `sectionProgress`（0–1 比例）和 `contentVersion`（内容修订号）。没有这些字段的旧档案继续有效；旧章节标题和数字锚点可解析为稳定 ID，notes/latest/best/completed 等数据保留。

后续新增可用课程需给稳定 lesson ID、每节 id，并设置 `introducedIn` 为递增的内容修订号（目前课程默认 1，新增可用课用 2）。只有旧内容版本中尚未出现的新课程可缺少记录并初始化为空；缺失既有课程记录依旧拒绝，避免放宽 F01。未知未来内容版本仍拒绝，并由 F02 保留原文。

修改章节展示标题时保持 id；为仍保存旧标题的备份保留 `legacyTitles`。旧数字锚点只作为当前顺序的兼容入口，新链接全部使用稳定 ID。词汇、实验和测验继续通过现有 Lesson 数据关联，无需复制页面。

这是从旧档案到新档案的兼容读取，不承诺旧程序能读取新稳定 ID。回滚前应导出档案；回到 F02 保护版本后不兼容原文应保持保护，不能删除 localStorage 来回滚。
