## 实际基线与改进

开始时 README.md 有一处表格空格修改，属已有未提交改动，保留且排除。已阅读 AGENTS、状态/交接、路线、A 实施和安全流程；检查了词库、课程词汇、AnnotatedText、VocabularyView、review-queue、StorageSession 和现有测试。

原有能力：34 个词条、搜索/课程/收藏/掌握筛选、闪卡/释义测验、课程收藏、学习/挑战模式、F01–F03 及异常存储保护。发现缺口：正文只有翻译和定义，缺例句与收藏；课程例句依赖正文截取/定义回退；普通复习队列会循环，缺明确本轮统计和状态调整入口；已展开词语在模式来回切换后不一定重新隐藏。

新增/改进：

- 正文解释在正常文档流展开，不使用绝对定位浮窗；提供中文翻译、英文定义、相关例句、收藏及收起。原生按钮支持 Enter/Space，关联 aria-controls/expanded；Escape 收起并返回术语按钮焦点。收藏使用同一档案字段。
- 课程词汇卡补例句；学习模式显示重要词语注释，挑战模式默认隐藏、点击展开。模式变化重置局部展开状态，偏好沿用 Provider 保存，不改 completed。词汇列表也支持按需中文；未就绪前禁止写入偏好。
- 保留 F03 的 reviewPosition/reviewIndex，增加本轮去重统计、有限轮次完成及重开，收藏/待巩固/已掌握筛选继续可用。错误词仍在待巩固，完成一轮不等于全部掌握。
- 闪卡聚焦后空格翻面、左右键导航，原生按钮保持触屏/键盘操作。快捷键只作用于卡片容器自身，不劫持输入框和按钮。
- 列表可显式标记已掌握/待巩固。该操作是一次自评，增加既有 attempts/correct；旧成绩、笔记、完成状态不变，不引入复杂 SRS。
- ID 为原 word 字符串（例如 packet），不依赖索引或翻译；不重命名原键。既有收藏/复习仍按 word 保存，无迁移、删除或放宽导入校验。

## 词汇数据检查

保留 34 项和唯一 word/中文释义；12 个课程词条换用明确书写的网络/安全例句，其余 22 个已有例句保留。定义和翻译审阅未发现需要批量改写的明显概念错误；不把例句等同定义，也不为凑数量扩词。

协议相关例句核对 [RFC 9499 DNS 术语](https://www.rfc-editor.org/rfc/rfc9499.html)与 [RFC 9293 TCP](https://www.rfc-editor.org/info/rfc9293/)，例如递归/权威角色及 ACK 的下一期待字节含义。其余定义保持原有简短教学表述，不声称完整覆盖协议规范。后续仍可人工精修自然度。
