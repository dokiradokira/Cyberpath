## 实现

- 每次真正提交完整测验保存唯一 ID、kind=quiz、课程、时间、总数、成绩及稳定题目 ID 对应的题干/选项/正确选项/实际选择/结果/解释/知识点与章节快照。重测产生新记录；重复提交同一 ID 幂等，不伪造旧历史。
- 错题本汇集曾经答错的题目及旧档案最近错题，可按课程、知识点筛选、跳转对应章节和查看解释。重练 kind=review 独立追加，不改变正式测验 latest/best，不删除历史错误。复习有明确结果，可再次练习。
- lastVisitedAt / lastQuizAt / completedAt 分开记录。旧 updated 保留，不把它猜作旧测验时间；首页最近成绩优先按真实 lastQuizAt，只有旧成绩时标注时间未知。
- Quiz Score Trend：真实正式测验正确率，时间排序，图中显示最近 20 次、完整明细保留全部。SVG 单点/空状态、0–100% 纵轴、次数横轴、可触摸/键盘访问的数据点，显示课程/日期/分数/百分比，按课程筛选，逐题结果可展开。
- Weak Topics：稳定题目→章节映射，统计正式测验和复习每次实际作答；错误率=错误次数/总作答次数，显示样本数，少于 3 次提示不足，不把错误次数直接当薄弱程度。提供解释链接及复习入口，重复练习计入样本而非独立学习者。
- 开放课程进度条只统计 availableLessons，Coming Soon 不进入分母；最近活动取真实访问/测验/复习时间。主题变量、响应式 SVG 和文字/列表明细，不引入图表库。

## 存储与迁移

仍使用 key `cyberpath.v1` / schema 1，新增可选 `study:{version:1,history:[]}` 和可选事件时间。parseProgress 是兼容读取/规范化入口：缺省字段保持缺省，不将 latest/best/旧错题推算成历史；原 favorites/reviews/notes/completed 均保留。旧错题可练习但其原始错误时间及次数未知，不加入统计。

独立 parseStudy 验证子版本、数组、容量、ID、课程、时间字符串、每题选项/索引/正确标志、总数和算术一致性，拒绝非法类型与未知子版本；先全量 parse 成功再 replace，失败不部分导入。F02 的 StorageSession 未修改，损坏 JSON/未知版本仍保留原 key 原文并暂停自动覆盖。F01/F03 及 B 词汇读写逻辑不改。

容量为全档案 100 条正式测验及复习记录，不滚动删除。到达上限会明确拒绝新提交，不宣称已完成；先导出后可由用户明确确认重置，网站不自动删除记录。导入仍有 1 MB 上限。未来扩充容量/档案归档需独立设计；本轮不提供无界增长。导出包含题目快照，回滚前必须备份；旧程序可能忽略新增字段，不承诺降级后继续写档保留历史。回滚用 revert，不改写已推送历史。
