## 数据迁移与升级

主存储为 IndexedDB `cyberpath.learning.v1`，meta/history/backups 同事务写入，按 generation/revision 管理。迁移先严格解析旧档案，保留原文备份，校验记录数后提交；刷新/中断回滚，重新打开可重试，不生成重复记录。新旧档案都不从 latest/best 虚构历史。

原 `cyberpath.v1` localStorage 仅为带 historyStorage 标记的最近 20 条兼容快照，不是完整历史备份；IDB 缺失时不能用它冒充完整档案。课程进度、笔记、偏好和词汇记录保留。写失败不报告测验保存成功，多标签冲突暂停保存并提示刷新核对，不提供自动合并。

导出 v2 `{format:"cyberpath",version:2,profile,history}` 包含完整历史；导入兼容合法旧 schema 1 档案，先验证、确认覆盖，再事务切换，失败保留原有效档案。备份文件上限 64 MB；浏览器配额仍有限，不能承诺无限存储。旧代记录/恢复原文会占用空间，不静默裁剪。

升级前建议在学习进度页导出完整 JSON，升级后检查课程完成、词汇收藏、笔记、错题、历史数量及导出重导入。兼容快照不是跨设备同步。降级前必须完整备份，旧程序可能忽略新字段；代码回滚用新的 revert 提交，不能删除用户存储或 reset 已推送历史。
