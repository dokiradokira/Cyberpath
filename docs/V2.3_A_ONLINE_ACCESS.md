# V2.3-A Personal Online Access 代码准备

日期：2026-11-11。分支：`feature/v2.3-a-online-access`，基于 `origin/master` 的合并提交 `ce6da4e`。本轮只做在线访问与部署准备，不新增云同步、账号系统或复杂离线缓存，不改学习档案数据结构。

## 本轮改动

- 新增 `vercel.json`：声明 Next.js、`npm ci` 安装和 `npm run build` 构建，不含重写、重定向或环境变量。
- 新增 `.vercelignore`：排除本地 `.next*`、测试报告和 Playwright 产物，避免上传旧构建。
- `next.config.ts`：在 `VERCEL=1` 时输出标准 `.next`，本地/CI 继续使用 `.next-v2`；否则 Vercel 可能找不到默认输出目录。
- `src/app/manifest.ts`：补齐 `id`、`scope`、`lang`、`dir`、`categories` 和图标 `purpose`。
- `src/app/layout.tsx`：加入 192/512 图标、180px Apple touch icon、`application-name`、`format-detection`，并同时输出标准与 Apple 的 web-app-capable 标记。
- 新增 `public/apple-touch-icon.png`：180×180、不透明，供 iPhone 主屏幕使用。

## HTTPS 兼容性核查

- 源码与静态脚本未发现外部 `http://`/`https://` 资源；页面、Manifest、图标和构建资源均为同源相对路径，不会在 HTTPS 页面产生混合内容。
- IndexedDB 为浏览器同源存储；HTTPS 域名与原有 HTTP/LAN 地址属于不同 origin，旧数据不会自动迁移。切换域名前应在学习进度页导出 v2 备份，再在新域名导入。
- `crypto.randomUUID` 有 `Math.random` 回退；IndexedDB 不可用/配额不足时仍沿用既有只读降级和原始数据保护。
- 没有注册 Service Worker，不宣称离线可用；本轮不增加复杂缓存。
- 学习档案 schema、IndexedDB 版本、localStorage key 和备份格式均未改动。

## 需要人工完成的 Vercel 操作

1. 在 Vercel 导入 `dokiradokira/Cyberpath`，选择 `feature/v2.3-a-online-access` 或合并后的 `master`。
2. Framework Preset 选 Next.js；Root Directory 保持仓库根；构建命令和安装命令由 `vercel.json` 提供。
3. Node.js 版本优先选 24.x（与本地 24.21.0 一致）；平台不提供时选 Next.js 16 支持的 22 LTS。
4. 不需要配置环境变量或数据库；本应用没有服务端学习数据。
5. 先部署 Preview，不应在未授权情况下直接提升为 Production。
6. 在 Preview HTTPS 地址检查 `/manifest.webmanifest`、`/apple-touch-icon.png`、图标 200 响应和 iPhone“添加到主屏幕”；再验证课程、词汇、测验及刷新后 IndexedDB 进度。
7. 若要从旧 HTTP/LAN 地址迁移，先导出完整 JSON，再在新 HTTPS 地址导入；不要期待跨 origin 自动共享。
